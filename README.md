# Kota Craft

Three.js で作った **Minecraft 風のブラウザボクセルゲーム**。

## 遊び方

ローカルの HTTP サーバで配信してブラウザで開きます (ES modules と import map を使うため `file://` では動きません)。

```bash
# Python がある環境なら
python3 -m http.server 8000

# Node がある環境なら
npx serve .
```

ブラウザで <http://localhost:8000> を開き、「クリックしてスタート」を押してください。

## 操作

| キー | 動作 |

## 特徴

### ゲームプレイ
- **64×32×64 のボクセルワールド** - FBM ノイズベースの自動生成 + 海 + 木
- **10 種類のブロック** - 草、土、石、原木、葉、砂、水、板、レンガ、丸石
- **DDA レイキャスト** - 正確なブロック選択と配置

### Minecraft 風機能
- **昼夜サイクル** - 時間経過で空の色が変化（朝→昼→夜）
- **ツールシステム** - 素手、木のツルハシ、石のツルハシ、鉄のツルハシ
- **ブロック採掘時間** - ブロックの硬さに応じて採掘時間が変動
- **ゲームモード** - クリエイティブモードとサバイバルモード
- **リアルタイム時間表示** - HUD に現在時刻を表示

### グラフィックス
- **Minecraft 風カラーパレット** - より正確なブロック色
- **光の当たり方** - 面の向きに応じた陰影表現
- **フォグ効果** - 距離に応じた大気表現
- **透明な水** - 海と水ブロックの透過処理

### その他
- 半透明水、AABB 衝突判定、ジャンプ/飛行機能
- 依存は Three.js (CDN) のみ、ビルド不要
- 拡張可能なブロック/ツール定義システム

## サーバーなしで遊ぶ

`play.html` は Three.js を同梱した 1 ファイル版です。ダウンロードしてダブルクリックするだけで、ネットにつながっていなくても遊べます。

`main.js` などを変更したら、次のコマンドで作り直します (esbuild と three@0.160.0 が必要)。

```bash
npm i --no-save esbuild three@0.160.0
node tools/build-play.cjs
```
