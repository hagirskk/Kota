# Kota Craft

Three.js で作った Minecraft 風のブラウザボクセルゲーム。

## 遊び方

ローカルの HTTP サーバで配信してブラウザで開きます (ES modules と import map を使うため `file://` では動きません)。

```bash
# Python がある環境なら
python3 -m http.server 8000

# Node がある環境なら
npx serve .
```

ブラウザで <http://localhost:8000> を開き、「クリックしてスタート」を押してください。

## 操作

| キー | 動作 |
| --- | --- |
| W / A / S / D | 移動 |
| Space | ジャンプ |
| Shift | ダッシュ |
| マウス | 視点操作 |
| 左クリック | ブロックを壊す |
| 右クリック | ブロックを置く |
| 1〜6 / ホイール | ブロック選択 |
| F | 飛行モード切替 |
| Esc | ポインター解除 |

## 特徴

- 64×32×64 のボクセルワールドを自動生成 (FBM ノイズ + 海 + 木)
- 草 / 土 / 石 / 木 / 葉 / 砂 / 水 / 板 / レンガの 9 種類のブロック
- DDA レイキャストによるブロック選択
- 半透明の水、フォグ、AABB 衝突判定、ジャンプ/飛行
- 依存は Three.js (CDN) のみ、ビルド不要
