操作方法

  • W / A / S / D : 移動
  • Space : ジャンプ
  • Shift : ダッシュ
  • マウス : 視点操作
  • 左クリック : ブロック破壊 / 攻撃
  • 右クリック : ブロック設置
  • 1〜9, 0 : ブロック選択
  • E : クラフト
  • T : 道具切替（ツルハシ / 剣）
  • C : クリエイティブ/サバイバル
  • F : 飛行モード
  • Esc : ポインター解除
  • タブレット : 左スティック移動 / 画面ドラッグ視点 / 右ボタン操作
